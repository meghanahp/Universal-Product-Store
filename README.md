# UniversalProductStore — API reference
### _Updated by PR #1_

## Endpoints

### GET /products
Returns a list of all products

### GET /products/:id
Returns a product by ID

### POST /products
Creates a new product

### PUT /products/:id
Updates a product

### DELETE /products/:id
Deletes a product
